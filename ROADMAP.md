# Roadmap

Current scope is a reviewed prerelease for a Windows server and Fedora 44
client. Improvements that still need work or verification:

- Signed installers and native desktop onboarding.
- Fresh elevated Windows install/update/uninstall on a clean test machine.
- Login/reboot and compositor permission persistence across desktop versions.
- More keyboard layouts and secure-desktop behavior.
- Multi-client UI, other Windows roles and other OS bundles.
- Automated engine compatibility and dependency-license checks before
  changing the pinned upstream version.

Free distribution and community maintenance remain the project direction.
No commercial-use restriction is added to the MIT license.
